Add or Update User Account

A mask naming a host, e.g. *!alice@home.example.org or *!*@home.example.org, is trusted without a password (auto-op for admins). With any other, such as *!*@* or *!alice@*, the user must log in (/msg bot login <password>): anyone can choose a nickname or ident.

Whoever is signed in to services (NickServ) with this account on that network is this user, without a password in the bot. Works where the server reports accounts (see IRC Settings).

IRC Networks

Each network is its own connection with its own channels (up to 4). A new nickname or channel list applies without disconnecting; other server settings reconnect that network automatically.

Report Channel

The bot tells your staff there what it does. It sets the channel password (+k) and sends nothing until the server confirms it, so the bot needs operator status there (it gets it by creating the channel). Staff join with /join #channel password.

Server Services

{channel} and {mask} are filled in. Leave a command empty to never send it. Mute mode: +q {mask} (Solanum), +b ~m:{mask} (SekurIRCd), +b m:{mask} (InspIRCd), +b ~quiet:{mask} (UnrealIRCd).

One per line, sent in order each time this network connects, before the channels are joined: /mode -x (the bot's own modes), /msg NickServ ..., or any line the server accepts. {nick} is the bot's nickname. Administrators can read these: keep the services password in its own field above.

Auto-Kick List

Anyone matching a mask is banned and kicked on sight (staff accounts are spared). Removing an entry here leaves bans already set on a channel; akick del on IRC lifts them too.

Status LED

The LED on the board, also shown next to the title, blinks slowly in the colour of the connection state. While someone is on the web pages, quick flashes fill the gap between two blinks. Saved changes apply within a second.

0 turns the LED off. Below 4 %, similar colours are hard to tell apart.

The board's red power LED is wired straight to its power supply, so it cannot be switched from here. If its light bothers you, cover it with a piece of opaque tape.
